# FrisianShorts
Script to get animation of puzzle from https://lidraughts.org/training/frisian/ and then put it on a background image with logo and text and save it as a video.

Simply edit the `createvideo.sh` script to change the background image, logo, text, and video settings and run it to generate the video.

## Usage
1. Create frames folder
2. Run script
  ``` bash
  bash ./createvideo.sh
  ```
